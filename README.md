# Calculator-Extra
Calculator Extra, sadece bir hesap makinesi olmanın ötesinde; kullanıcı deneyimi, estetik tasarım ve işlevselliği bir araya getiren web tabanlı bir uygulamadır. Mavi ve beyaz tonlarının huzur verici uyumuyla tasarlanan bu proje, modern Glassmorphism (buzlu cam) efektleriyle donatılmıştır.
